# Responding to Technical Committee Feedback

Use this checklist when the Technical Committee (TC) requests changes to your
proposal during the [Project Acceptance Process](../governance/project-lifecycle-policy.md).

## Acknowledge each request

- [ ] Restate every TC request in your own words to confirm understanding.
- [ ] Ask clarifying questions before starting on anything ambiguous.

## Document the changes you made

- [ ] Summarize what changed and link to the relevant commits or edits.
- [ ] Map each change back to the specific TC request it addresses.

## Explain any declined suggestions

- [ ] Note which suggestions you did not adopt.
- [ ] Give a clear rationale for each decision.

## Confirm readiness for re-review

- [ ] Verify all agreed-upon changes are complete.
- [ ] Request re-review and name your TC sponsor as the point of contact.
