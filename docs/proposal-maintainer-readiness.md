# Proposal Maintainer-Readiness Checklist

Before submitting a project proposal to the Agentic AI Foundation (AAIF),
prospective projects should confirm they are ready to describe how the project
is maintained and governed. Use this short checklist to prepare.

## Checklist

- **Core maintainers:** Identify the names of the project's core maintainers,
  including anyone who is not among those submitting the proposal.
- **Organizational diversity:** Note whether maintainers represent more than one
  organization, so reviewers can assess the diversity of maintainership.
- **Governance and decision-making:** Describe the project's leadership team and
  how decisions are made, referencing any documented governance practices.
- **Communication channels:** List the project's official communication channels
  (for example Discord, Slack, or mailing lists), if any.
- **Expected time commitment:** Set expectations for the ongoing time commitment
  maintainers can offer to sustain the project.

When ready, complete the proposal form at
[../.github/ISSUE_TEMPLATE/project-proposal.yml](../.github/ISSUE_TEMPLATE/project-proposal.yml).
