# Proposal Submission Self-Check

A short pre-submission checklist that maps to the AAIF
[project proposal issue form](../.github/ISSUE_TEMPLATE/project-proposal.yml)
and the [project lifecycle policy](../governance/project-lifecycle-policy.md).

## Required form fields (all must be completed)

- [ ] Project Name
- [ ] Project Description
- [ ] Alignment with AAIF Mission
- [ ] Relation to Existing AAIF Projects
- [ ] Example Use Cases and Evidence of Adoption
- [ ] GitHub Repository URL
- [ ] License
- [ ] Governance Model
- [ ] CI/CD & Release Workflow
- [ ] Public-Facing Contribution Process for Specifications
- [ ] Publicly Accessible Issue Tracker
- [ ] External Project Dependencies
- [ ] Maintainers & Contributors
- [ ] Leadership Team & Decision Process
- [ ] Roadmap
- [ ] Security
- [ ] Website URL
- [ ] Application contact name(s) and email(s)
- [ ] Contributing or sponsoring entity signatory information

## Before you submit

- [ ] Sponsor info: add a Technical Committee Sponsor when one is known (optional).
- [ ] Lifecycle stage: note your preferred stage (Growth or Impact) as a
      non-binding preference — the TC determines the initial stage.
- [ ] Trademark: confirm the checkbox agreeing to donate all project trademarks
      and accounts to the AAIF if the project is accepted.
- [ ] Review the rendered issue preview for formatting and completeness before
      clicking submit.
