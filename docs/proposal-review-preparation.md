# Preparing a Proposal for Technical Committee Review

Use this checklist after submitting a project proposal to help it move smoothly
through Agentic AI Foundation (AAIF) Technical Committee (TC) review.

## Problem statement & scope

- [ ] The problem the project solves is stated clearly and concisely.
- [ ] The project's scope, value, origin, and history are described.
- [ ] Alignment with the AAIF mission and existing projects is explained.

## Governance & maintainers

- [ ] A governance model is documented (e.g. GOVERNANCE.md practices).
- [ ] At least two core maintainers from different organizations are named.
- [ ] The leadership team and decision-making process are described.

## Lifecycle-stage preference

- [ ] A preferred lifecycle stage (Growth or Impact) is stated.
- [ ] You understand this preference is a non-binding input: the TC determines
      the appropriate initial stage for an accepted project. See the
      [Project Lifecycle Policy](../governance/project-lifecycle-policy.md).

## Requested follow-ups

- [ ] Comments and change requests from the TC or community are tracked.
- [ ] Each requested change is resolved, since the project must make these
      changes in order to progress.
- [ ] Responses to reviewers are prompt and clearly reference the changes made.
